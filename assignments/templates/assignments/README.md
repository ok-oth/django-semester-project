# Student Assignment & Task Management System

A Django web application designed for university and college students to organize, create, update, filter, and track academic assignments and deadlines.

## Features
- Student account registration, login, and logout
- User-scoped assignment management (students only see and manage their own items)
- Full CRUD workflows: create, view, filter/search, edit, toggle completion status, and delete assignments
